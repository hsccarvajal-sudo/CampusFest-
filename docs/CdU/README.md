# Casos de uso — CampusFest

Diagrama `CampusFest_Casos_De_Uso.drawio`: dos páginas, **Estudiante** y **Organización**, copiadas del contenido de la guía (página 2). Es la fuente de los nueve casos de uso documentados en esta carpeta.

- Consultar eventos (compartido por los demás mediante `«include»` según la hoja).
- Consultar cupos.
- Reservar.
- Confirmar reserva.
- Cancelar reserva (incluye el disparador de 10 minutos en la figura de organización).
- Registrarse (asistencia).
- Gestionar un evento.
- Generar reporte de reservas.
- Generar reporte de asistencia.

Las fichas Markdown contienen precondición, poscondición, trazabilidad y vínculo a cada análisis. No se ha creado un caso de uso autónomo llamado "Vencimiento" porque la fuente identifica al Tiempo con **Cancelar reserva**.
